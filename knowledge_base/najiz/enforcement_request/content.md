The system may display two courts in the drop-down list based on the information entered previously. For example, if the enforcement respondent's residential address is in a different city from the place where the document was issued, the system will only display the two cities in the drop-down list to select the court.
However, if no court is available in the enforcement document information, or if the document does not have a field to select the court or the place where it was issued, the system will select the court by default based on the following:
• The city of the residential address of the enforcement respondent, if any
• The city address of the enforcement applicant
If the city of the residential address of the enforcement respondent or the enforcement applicant city address was not found, the system will not allow the request to be submitted and the applicant will be notified that determining the territorial jurisdiction of the request is required.
