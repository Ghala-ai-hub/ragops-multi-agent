# RAGOps Frontend V2

This revision focuses on presentation quality and information hierarchy without changing the backend workflow.

Key changes:
- Rebuilt the Overview hero and control-loop visualization to remove overlap and dead space.
- Made the navigation denser and more product-like.
- Compressed RAGOps in Action into a command-console layout with six scenario presets, inline query/run controls, a smaller evidence console, and a clearer live trace.
- Restyled validation, HITL, KPI, and evidence sections.
- Reworked the Dashboard charts to reduce label overlap and improve readability.
- Replaced the flat architecture row with a workflow board that separates agents from control/system components.
- Preserved the real backend contracts, verified demo data, LangGraph/HITL behavior, and adapter layer.
